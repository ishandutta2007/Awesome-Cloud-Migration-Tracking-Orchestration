## 🏢 SaaS / Commercial Platforms

The cloud migration tracking and orchestration market spans **hyperscaler native tools** (AWS, Azure, Google) that provide **unified tracking and automated workflow execution**, and **specialized platforms** (Tidal, Flexera, Device42) that offer **application-centric planning, dependency validation, and business case modeling**. **AWS Migration Hub** provides a single location to track migrations across multiple AWS tools, with **Migration Hub Orchestrator** offering **predefined templates** for automated migration workflows . **Azure Migrate** supports **server, database, web app, and virtual desktop migrations** with **dependency analysis** for high-confidence planning . **Tidal's integrated suite** connects **Calculator (business case)**, **Accelerator (assessment and planning)**, **LightMesh (IPAM)**, and **Saver (cost optimization)** in an end-to-end migration lifecycle .

## 🔓 Open-Source GitHub Projects

*Sorted by GitHub_Stars_Count (Descending)* 🌟

- **[Cloud-Migrator (Cloud-Barista)](https://github.com/cloud-barista/cloud-migrator)** [![Stars](https://img.shields.io/github/stars/cloud-barista/cloud-migrator?style=social&color=white)](https://github.com/cloud-barista/cloud-migrator/stargazers)  
  **Integrated cloud migration orchestration platform**, open-source. **Scans all IT assets** (infrastructure, software, data) and **migrates them all at once** . **10+ subsystems**: **CM-Honeybee** (asset collection), **CM-Ant** (cost/performance evaluation), **CM-Cicada** (workflow management), **CM-Beetle** (infra migration), **CM-Grasshopper** (software migration), **CM-Centipede** (data migration), **CM-Butterfly** (GUI portal), **CM-Mayfly** (runtime operation), **CB-Tumblebug** (multi-cloud infra management), **CB-Spider** (cloud integration) . **The most comprehensive open-source migration orchestration platform** — covers the complete migration lifecycle. 🏗️

- **[Prophet (Cloud-Discovery)](https://github.com/Cloud-Discovery/prophet)** [![Stars](https://img.shields.io/github/stars/Cloud-Discovery/prophet?style=social&color=white)](https://github.com/Cloud-Discovery/prophet/stargazers)  
  **Automated resource collection, analysis, and management toolset for cloud migration and disaster recovery**, open-source. **27 stars** . **Modern Web interface and powerful CLI** for comprehensive collection and analysis of **physical machines and VMware environments**. **Core value**: automated collection via multiple protocols (**nmap, Ansible, WMI, VMware API**), **visualized application topology canvas**, **automatic data masking** to remove sensitive information, and **containerized deployment** with Docker Compose . **Web UI features**: host management, application management with visual canvas, scanning tasks, VMware platform management, tag management, and data import/export . **The most complete open-source migration discovery and analysis toolset**. 🔍

- **[Cloud Migration MCP](https://github.com/chrishorne74/cloud-migration-mcp)** [![Stars](https://img.shields.io/github/stars/chrishorne74/cloud-migration-mcp?style=social&color=white)](https://github.com/chrishorne74/cloud-migration-mcp/stargazers)  
  **MCP server for cloud migration assessment, strategy, and planning**, open-source . **7 Rs Strategy Engine** recommends Rehost, Replatform, Repurchase, Refactor, Retire, Retain, or Relocate based on workload attributes . **Migration Assessment** scores workloads **0–100 across 10 industry-standard criteria** (business criticality, complexity, vendor support, cloud readiness, cost, age, SaaS availability, data sensitivity, documentation, compliance) . **30+ built-in guardrails** across Dependency, Security, Compliance, Data, Architecture, Operations, and Cost categories . **Candidate Scoring & Ranking** for up to 50 workloads. **Wave Planning** respecting dependencies and affinity groups. **Cost Estimation** with ROM (±50%) and ROI break-even . **Draw.io Diagrams** with native AWS/Azure/GCP shapes. **The most comprehensive open-source migration planning engine** — agent-ready with MCP protocol. 🚀

- **[CM-Ant (Cloud-Barista)](https://github.com/cloud-barista/cm-ant)** [![Stars](https://img.shields.io/github/stars/cloud-barista/cm-ant?style=social&color=white)](https://github.com/cloud-barista/cm-ant/stargazers)  
  **Cloud migration validation framework**, open-source . **Validates performance, pricing, and cost-effectiveness before and after migration** . **Two main functionality categories**: **Prediction of cloud infrastructure transition pricing** (price information for recommended specs, operational cost for specific CSPs, predicted cost information) and **on-demand performance evaluation** (performance evaluation of applications, validation based on results) . **Integrated with CB-Tumblebug and CB-Spider** for multi-cloud infrastructure management. **Under active development** — not yet recommended for production use . 🧪

- **[go-migrator](https://github.com/cloud-barista/go-migrator)** [![Stars](https://img.shields.io/github/stars/cloud-barista/go-migrator?style=social&color=white)](https://github.com/cloud-barista/go-migrator/stargazers)  
  **Cloud migration automation tool**, open-source. **Part of the Cloud-Barista ecosystem** for multi-cloud migration. **Go-based** migration orchestration. 🔧

## ⚠️ Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement. ℹ️
- **AWS Migration Hub stopped accepting new customers on November 7, 2025** — existing customers can continue using the service, but **AWS Transform** is the recommended replacement with AI-driven automation and enhanced capabilities . **All current Migration Hub features are available in AWS Transform with improved functionality** .
- **Azure Migrate remains free** for discovery, assessment, and migration planning, with **partner tools potentially charging separately** . **Azure Copilot migration agent (preview)** provides conversational planning using project data .
- **Tidal Cloud's integrated suite** connects business case modeling, assessment, network management, and cost optimization in one platform. **One financial services firm achieved $4.2M in annual savings** and **reduced migration planning time from 4 months to 6 weeks** .
- **Open-source tools (Cloud-Migrator, Prophet, Cloud Migration MCP) are not turnkey** — **Cloud-Migrator requires Docker Compose deployment** with 10+ subsystem dependencies . **Prophet requires Docker and network access to target systems** . **Cloud Migration MCP requires MCP client integration** . **Always validate migration workflows with a proof-of-concept** before committing to production timelines. 🗺️
